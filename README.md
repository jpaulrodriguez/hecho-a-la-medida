# Hecho a la medida

Guías técnicas para construir herramientas propias con IA, sin ser programador. Por Jonathan Rodríguez.

Sitio: https://jpaulrodriguez.github.io/hecho-a-la-medida/

1. Diseña tu primera herramienta con IA antes de construirla
2. Que la IA no invente
3. Que corra solo sin perder el control
4. Entregar y mantener sin sustos

El sitio se genera desde la fuente privada con `sistema/publicar.py`; no se edita a mano.
